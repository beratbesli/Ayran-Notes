# Changelog

All notable changes to Ayran Notes are documented here. The project follows semantic versioning while it is in active development.

## Unreleased

- Added pull-request and main-branch test, lint, compile, and package-build checks.
- Made release tooling reproducible by pinning and verifying linuxdeploy.
- Added SHA-256 checksums to future GitHub releases.
- Added a security policy and automated dependency updates.

## 0.0.2 - 2026-09-01

- Added local Git-backed note history, version previews, safe restore, and deleted-note recovery.
- Improved save safety and source-of-truth handling for Markdown files.

## 0.0.1 - 2026-09-01

- Initial public release with Markdown editing, themes, localization, import/export, and Linux packages.
