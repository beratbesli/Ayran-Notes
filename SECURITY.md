# Security Policy

## Supported versions

Security fixes are provided for the latest published release and the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's security advisory form:

<https://github.com/beratbesli/Ayran-Notes/security/advisories/new>

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include private notes, credentials, or other personal data in a public issue.

## Data model

Ayran Notes stores notes and their local Git history on the user's computer. It does not automatically upload notes to GitHub or another remote service. Users should still protect their notes directory and device backups according to the sensitivity of their content.
